// about

Curious builder. Systems thinker. Debugger by nature.

It started in 2016 with flashing custom ROMs on phones to see what would break. Ten years later I’m still doing the same thing, just with servers, bots and databases instead of a bootloader.

Along the way: Telegram bots, cloud hosting, Heroku, MongoDB, Redis and a lot of git push. I learn by building, shipping and fixing, from practical automation to ideas that don’t have a name yet.
