// about

Curious builder. Systems thinker. Debugger by nature.

It started in 2016 with flashing custom ROMs on phones to understand how things really work beneath the surface. That curiosity evolved into a broader obsession with systems, automation, backend logic, and tools that make life easier for users and teams alike.

Over the years, I’ve built Telegram bots, cloud-connected workflows, storage and automation tools, and experiments around real problems that needed practical engineering. I learn by building, shipping, and iterating — whether the challenge is backend reliability, API design, automation, or making a system feel smooth and dependable for real users.

$ git log --oneline

From curiosity to building systems.

2016

Flashed my first custom ROM

Used Linux, shell access, and device-level debugging to understand boot flows, Android internals, and how system changes affect real hardware. This was my first deep dive into how operating systems actually behave under the hood.

2017–18

Linux, hosting, and backend basics

I started learning Linux, shell scripting, hosting workflows, and the fundamentals of backend infrastructure. That pushed me from curiosity into understanding servers, deployment, and how systems connect in the real world.

2018–20

Python + Telegram APIs + automation

This was the period where I used Python, Telegram bot APIs, file handling, and cloud workflows to build practical automation tools like ChatGptBot, google-drive-telegram-bot, and File-Sharing-Bot. I learned how to design services that actually solve user problems and handle real inputs reliably.

2020–22

Docker, MongoDB, Redis, AWS

I expanded into Docker, Linux environments, MongoDB, Redis, and cloud deployment patterns to make my tools more resilient and production-ready. This is where I moved from single-purpose bots to infrastructure-aware systems that needed stability and scalability.

2022–24

Python + Go + system tooling

By this stage I was using Python for backend automation and Go for remote execution and service logic, alongside Linux and shell tooling for operations. Projects like xruncode, Terminal-Bot, and stream/search bots sharpened my understanding of command execution, automation, and system design.

2024–26

AI tools, automation, and workflow learning

I focused on AI-related tooling, prompt-driven workflows, automation stacks, and practical experimentation with Python-based integrations and intelligent assistants. This period helped me explore how LLMs and automation tools can be applied to real workflows while keeping my engineering instincts grounded in problem solving.

2026–30

DSCE CSE'30

Dayananda Sagar College of Engineering, Bengaluru. I’m continuing this journey by combining systems thinking, practical project experience, and stronger engineering fundamentals to build software that solves meaningful problems.
