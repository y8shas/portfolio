# Portfolio

This repository contains the personal portfolio site for Yash, built as a modern tech-themed static website.

## Features
- Dark professional landing page
- Project showcase section
- Tech stack chips
- Responsive layout for mobile and desktop
- GitHub Pages ready

## Deploy to GitHub Pages
1. Push this repository to GitHub
2. Go to repository settings
3. Open Pages
4. Set source to GitHub Actions or branch deployment if needed
5. Use the root folder for static hosting

## Local preview
Open `index.html` in a browser or serve the folder with a simple static server.
